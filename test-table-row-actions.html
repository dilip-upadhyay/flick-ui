⚡ Table Grid Row Actions Feature Test

🔍 Test Instructions:

  1. Click the "Test Row Actions Demo" button to load the enhanced table component
  2. Look for the "Actions" column on the right side of the table
  3. Each row should display action buttons with icons
  4. Test the following actions:
    • Edit (pencil icon) - Should trigger update action
    • Delete (trash icon) - Should show confirmation dialog
    • Activate/Deactivate (power icon) - Custom action
    • View Details (eye icon) - Custom action
  5. Hover over action buttons to see tooltips
  6. Test with different table features (pagination, sorting, filtering)
  7. Verify actions work with row selection

🚀 New Row Actions Features:

  • Configurable Actions: Define custom actions per table
  • Action Types: Built-in support for 'delete', 'update', and 'custom' actions
  • Confirmation Dialogs: Optional confirmation messages for destructive actions
  • Conditional Actions: Actions can be disabled based on row data
  • Visual Styling: Color-coded actions (primary, accent, warn)
  • Tooltips: Helpful tooltips for better UX
  • Event Handling: Complete action data emitted for parent components
